## Backlog policy

- The maintainer adds future feature requests here when they want them tracked.
- Before building a listed item, verify the actual code first. If the feature is already implemented, update or remove the backlog item instead of rebuilding it.
- Do not invent backlog items just because a feature seems useful.
- Keep this file focused on active future work. Historical implementation plans are summarized in [`PlanningSummary.md`](PlanningSummary.md).
