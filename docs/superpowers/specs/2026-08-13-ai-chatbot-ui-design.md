## 1. Executive Summary & Goals

The AI Chatbot interface currently relies on hardcoded dark/emerald colors (`bg-neutral-900`, `bg-emerald-950`), creating a visual mismatch against atTrack's light theme and brand design system. Furthermore, key AI assistant capabilities—such as system persona presets, slash commands, side-by-side artifact preview, text-to-speech, and rich markdown code rendering—are absent or unpolished.

This project delivers a complete brand-aligned overhaul and feature-packed upgrade to transform the AI Chatbot into a state-of-the-art AI Assistant Studio.

### Key Objectives
1. **100% Brand & Token Alignment**: Standardize all surfaces to use atTrack semantic tokens (`bg-background`, `bg-card`, `bg-muted`, `border-border`, `text-foreground`, and brand lime `--primary: #bef264` / `#a3e635`). Seamless support for both Light and Dark modes.
2. **Radius Ladder Compliance**: Enforce strict step-down radius hierarchy (`rounded-3xl` modals, `rounded-2xl` cards/bubbles, `rounded-xl` dropdowns, `rounded-lg` buttons/inputs, `rounded-full` pills/badges).
3. **Comprehensive AI Power Options**:
   - **AI Persona Switcher**: System prompt presets (*Career & ATS Coach*, *Technical Interviewer*, *Cold Outreach Specialist*, *Code Reviewer*, *General Assistant*).
   - **Slash Commands Popover**: Typing `/` inside the chat textarea triggers quick prompt options (`/resume`, `/interview`, `/cold-email`, `/code-refactor`).
   - **Side-by-Side Artifact Canvas**: Toggleable split drawer for inspecting code snippets, markdown documents, and structured summaries generated by the AI.
   - **Enhanced Message Toolbar**: Copy response, Thumbs Up/Down feedback, Retry response, Edit user message, Text-to-Speech (Read Aloud), Share thread, and Export (Markdown/JSON).
   - **Reasoning Model Collapsible Block**: Accordion support for displaying thinking process for reasoning models (DeepSeek R1 / o1 / Gemini Thinking).

### 2.1 Color & Visual Aesthetics

- **Chat Input Container**: `bg-card/90 border border-border/80 shadow-2xl backdrop-blur-xl rounded-2xl` with a subtle lime ring focus state (`focus-within:ring-2 focus-within:ring-primary/40`).
- **Sidebar**: `bg-card/70 border-r border-border backdrop-blur-md`. Threads active state highlighted with `bg-accent text-accent-foreground font-semibold border border-primary/30`.
- **User Messages**: `bg-primary text-primary-foreground font-medium rounded-2xl rounded-br-xs shadow-xs`.
- **Assistant Messages**: `bg-card text-card-foreground border border-border rounded-2xl rounded-bl-xs shadow-xs`.
- **Primary Accents**: Lime gradient (`.bg-gradient-brand`) for key action buttons (`New Chat`, active toggles) and `.text-gradient-brand` for hero headers.

### 2.2 Persona Presets

| Persona ID | Title | Description | System Prompt Focus |
|---|---|---|---|
| `general` | General Assistant | Helpful & versatile career & tech assistant | General career & tech support |
| `ats_coach` | ATS & Resume Coach | Resume optimization & ATS keyword alignment | Formatting, impact metrics, ATS score optimization |
| `interviewer` | Interview Prep Coach | Behavioral & technical mock interviewer | STAR method questions & constructive critique |
| `outreach` | Outreach Specialist | High-converting networking & cold emails | Concise, impactful recruiter & manager outreach |
| `code_architect` | Code Architect | Code review, refactoring, & debugging | Modern TypeScript/React, edge cases, performance |

### 2.3 Slash Command Autocomplete

When the user types `/` in the prompt input, a floating suggestion menu pops up:
- `/resume` -> Insert Resume Review prompt
- `/interview` -> Insert Mock Interview starter
- `/cold-email` -> Insert Cold Outreach template
- `/code` -> Insert Code Refactoring prompt
- `/clear` -> Clear active chat history
- `/persona` -> Switch system persona

### 2.4 Artifact Canvas (`chat-canvas.tsx`)

- Slide-over drawer on the right side (~45% screen width on desktop).
- Displays extracted code blocks, markdown reports, or formatted resume reviews with syntax highlighting, line numbers, copy button, and download file option.
