# Project: atTrack sqlite-vec & Hybrid RAG Retrieval Integration

## Architecture
atTrack implements a Three-Tier Retrieval Architecture over a single embedded SQLite database (`attrack.db` via `node:sqlite`'s `DatabaseSync`):
1. **Tier 1 (Standard Relational SQL)**: Fast ACID transactional queries for jobs, kanban board lists, applications, interviews, contacts, and deadlines.
2. **Tier 2 (SQLite FTS5 Full-Text Search)**: BM25-ranked lexical search via `omni_search_index` for global command palette (⌘K) and keyword filtering.
3. **Tier 3 (sqlite-vec Vector RAG)**: Native C-extension (`vec0` virtual tables) loaded inside SQLite for semantic similarity search over 768-dimensional embeddings generated by BYOK AI providers (Gemini `text-embedding-004` and OpenAI `text-embedding-3-small`).

Data flow:
```
[User Documents / Jobs / Notes / Memories]
             │
             ▼
[lib/ai/embeddings.ts: Recursive Chunker (300-500 tokens)]
             │
             ▼
[BYOK Embeddings Generator (Gemini / OpenAI -> 768-dim float32)]
             │
             ▼
[SQLite Storage: document_chunks + vec0 (vec_document_chunks, vec_memories)]
             │
             ▼
[lib/ai-chatbot/retrieval/hybrid.ts: Relational Pre-filtering + Vector KNN]
             ├──> Chatbot Grounding & Memories (/chatbot)
             ├──> Resume & Job Fit Matching (InsightsTab)
             └──> Grounded AI Tools (AiToolsTab)
```

## Interface Contracts

### `lib/db/sqlite.ts` ↔ Vector Tables
- Schema version: `CURRENT_SCHEMA_VERSION = 7`
- Extension load: `sqliteVec.load(db)` before `addMissingColumns` and schema execution.
- Vector tables:
  - `vec_memories`: `id INTEGER PRIMARY KEY AUTOINCREMENT, embedding float[768] distance_metric=cosine, +memory_id TEXT, +user_id TEXT`
  - `document_chunks`: `id INTEGER PRIMARY KEY AUTOINCREMENT, user_id TEXT, source_id TEXT, source_type TEXT, chunk_index INTEGER, chunk_text TEXT, token_count INTEGER, created_at TEXT, updated_at TEXT`
  - `vec_document_chunks`: `id INTEGER PRIMARY KEY, embedding float[768] distance_metric=cosine, +user_id TEXT, +source_id TEXT`

### `lib/ai/embeddings.ts` ↔ Indexing & Retrieval
- Functions:
  - `chunkText(text: string, options?: { maxTokens?: number; overlapTokens?: number }): string[]`
  - `generateEmbedding(text: string, userId?: string): Promise<Float32Array | null>`
  - `generateEmbeddingsBatch(texts: string[], userId?: string): Promise<(Float32Array | null)[]>`
  - `indexEntityChunks(params: { userId: string; sourceId: string; sourceType: 'job_description' | 'job_notes' | 'resume' | 'document'; text: string }): Promise<void>`
  - `deleteEntityChunks(userId: string, sourceId: string): Promise<void>`
  - `indexMemoryVector(memoryId: string, userId: string, title: string, description: string): Promise<void>`
  - `deleteMemoryVector(memoryId: string): Promise<void>`

### `lib/ai-chatbot/retrieval/hybrid.ts` ↔ Chatbot & Feature Integrations
- Functions:
  - `searchDocumentChunksHybrid(params: { userId: string; queryEmbedding: Float32Array; sourceTypes?: string[]; sourceIds?: string[]; limit?: number }): Promise<ChunkSearchResult[]>`
  - `getSemanticMemories(userId: string, query: string, topK?: number): Promise<RetrievedMemory[]>`
  - `matchJobRequirementsToResume(jobId: string, resumeId: string, userId: string): Promise<FitBreakdownResult>`
